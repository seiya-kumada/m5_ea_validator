プロジェクト名: mt5-ea-validator

MetaTrader 5 の Strategy Tester をコマンドラインから自動実行する
Python製のEA検証ツールを作りたい。

最終的には複数EAについて、
WFO、Capital Stress、Execution Delay Stress、
Transaction Cost Stressなどを自動実行できる
汎用的なEA検証ツールにしたい。

今回は最初の実装として、
Capital Stress Test の QQ（Quantum Queen X）/ WF1 だけを対象にする。

==================================================
■ 今回の検証目的
==================================================

Capital Stress Testでは、
EA、パラメータ、期間、Lot、モデリング、約定条件などを固定し、
初期口座資金（Deposit）だけを変更する。

資金量を変えたときに、

- Net Profit
- Equity Drawdown
- 取引数
- PF
- RF
- Sharpe Ratio

などがどう変化するかを確認する。

特に、
資金不足、証拠金不足、Stop Out、注文不能などによって、
EAの取引系列そのものが変化する資金水準を調べたい。

==================================================
■ 今回対象とするEA
==================================================

EA:
Quantum Queen X MT5

MT5上にインストール済みのEAを使用する。

EAの実際のファイルパスについては、
ローカル環境を調査して確認すること。
推測でパスを決めないこと。

==================================================
■ QQ WF1 の期間
==================================================

WF1のForward検証期間:

2025-07-01 ～ 2025-09-30

重要:
Capital Stress Testではこの期間だけを通常バックテストする。

WFOの再最適化は行わない。
OptimizationはOFF。
Forward機能もOFF。

このWF1でWFOによって既に選択されたパラメータを固定して使用する。

==================================================
■ QQ WF1 の固定パラメータ
==================================================

InpOrdersMax = 10
InpUseNfpFridayFilter = true
InpTradingFridayNight = false

Lot = fixed 0.01

DD Mode = 0 / OFF
DD Value = 0

その他のパラメータについては、
現在使用しているQQ WF1のsetファイルの値をそのまま維持する。

Capital Stress Testのためにパラメータを変更したり
再最適化したりしないこと。

==================================================
■ Strategy Tester 共通条件
==================================================

Symbol:
XAUUSD

Timeframe:
H1

Test period:
2025-07-01 ～ 2025-09-30

Model:
Every tick based on real ticks
（リアルティックに基づいたすべてのティック）

Execution delay:
No Delay
（遅延ゼロ、理想的な実行）

Leverage:
1:500

Currency:
USD

Optimization:
OFF

Forward:
OFF

Lot:
0.01 fixed

■ 初期資金

ただし、最初から4本全部を実行しない。

==================================================
■ Phase 1: まず確認すること
==================================================

いきなりコードを書き始める前に、
現在のWindows環境を調査して以下を確認すること。

1. terminal64.exe の実際の場所
2. 使用しているTitanFX MT5のデータフォルダ
3. Quantum Queen X MT5のEAファイルの場所
4. Strategy Tester用setファイルの場所
5. QQ WF1用setファイルが既に存在するか
6. Strategy Testerのレポート保存先
7. Pythonの実行環境

複数のMT5がインストールされている場合は、
TitanFXで現在手動検証に使用しているMT5を特定すること。

不明な点を推測して実装しないこと。

確認した内容と、
どのような構成で実装するかを最初に提示すること。

==================================================
■ Phase 2: 自動実行
==================================================

PythonからMT5 Strategy Tester用のiniファイルを生成し、

terminal64.exe /config:<ini file>

を使ってバックテストを起動する。

1つのテストが完全に終了してから
次のテストを開始すること。

並列実行はしない。

最初は次の2本。

QQ / WF1 / Deposit 3000 USD
QQ / WF1 / Deposit 1500 USD

この2本ではDeposit以外の条件を完全に同一にすること。

==================================================
■ レポート
==================================================

各テストのHTMLレポートを別ファイルで保存する。

例:

QQ_WF1_CAPITAL_3000.htm
QQ_WF1_CAPITAL_1500.htm

将来的には、

QQ_WF1_CAPITAL_1000.htm
QQ_WF1_CAPITAL_6000.htm

も追加する。

既存レポートを誤って上書きしない設計にすること。

==================================================
■ 実行ログ
==================================================

Python側でも実行ログを残す。

最低限、

- EA
- WF番号
- 開始日
- 終了日
- Deposit
- 使用したsetファイル
- 使用したiniファイル
- MT5起動時刻
- MT5終了時刻
- 成功 / 失敗
- レポートファイル名

を記録する。

==================================================
■ 自動化結果の検証
==================================================

まずDeposit=3000 USDの結果を、
以前手動で実行したQQ WF1 / No Delayの結果と比較する。

手動結果の目安:

Net Profit: +53.98 USD
PF: 約1.26
RF: 約0.54
Equity DD: 約3.35%
Trades: 147

完全に同じテスト条件であれば、
原則として同一の結果になることを期待する。

一致しない場合は、
そのまま次のテストへ進まず、

- setファイル
- 日付
- real ticks設定
- EAパラメータ
- Lot
- Deposit
- leverage
- execution delay
- symbol
- timeframe

などの差を調査すること。
