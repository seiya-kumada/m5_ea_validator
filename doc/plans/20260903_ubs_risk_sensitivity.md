# UBS資金管理パラメータ感応度・同一リスク比較 実装計画

日付: 2026-09-03

## 目的

UBS Gold 7戦略について、原setの売買ロジックを維持したまま、実際の約定ロットを決める入力を実測で特定する。その後、約1年実ティックの最大Equity DDを5.0%（許容4.5%～5.5%）へ近づけた派生setを作り、同程度の過去損失リスクで収益効率を比較する。

基準の正本は`doc/decisions/20260903_ubs_same_risk_criterion.md`とする。

## 正本と固定条件

- 原set正本: `data/ubs_strategy_comparison/faithful_augmented_sets/20260902T143126585336_b4e7cdd1/`
- 基準結果: `data/ubs_strategy_comparison/model_comparison_1y/20260902T162029093739_4e2ec09f/`
- Deposit / Currency / Leverage: 3,000 USD / USD / 1:500
- Symbol / Tester時間足: XAUUSD / H1
- モデル / 期間: Every tick based on real ticks / 2025-07-01～2026-06-30
- Execution: No Delay
- `MaxTrades`、エントリー、決済に関係する値は変更しない。
- 原setと既存結果は上書きしない。

## 実装段階

### 1. 既存結果のロット監査

- MT5 HTMLのdeal表から、新規建てdealのvolumeを抽出する。
- 戦略ごとに初回、最小、最大、平均、合計、件数を保存する。
- 既存のdeal日時・方向・価格ハッシュと会計集計を変更しない。

### 2. 感応度パイロット

- 代表戦略を、低DD・高DD・異なる`LotPerBalance_step`から選ぶ。
- 短い実ティック期間で、候補入力を1項目ずつ変更する。
- `StartLots`、`LotPerBalance_step`、`HistoricalMaxDD`を優先し、実約定ロットへの影響を測る。
- 1回目はロット縮小方向を中心にし、拡大は原設定の2倍以内とする。
- 候補入力がレポートへ正しく適用されたことを必須ゲートにする。

### 3. 約1年DD調整

- 実測で有効と確認したロット入力だけを使って、戦略別の派生setを生成する。
- 基準DDから概算した倍率で実ティックテストを行い、4.5%～5.5%に入らなければ安全な範囲で再調整する。
- 証拠金不足、取引拒否、入力不一致、ロット以外の想定外分岐をFAILとする。

### 4. 四半期安全確認

- 同一リスク派生setをWF1～WF4で確認する。
- 各WFの最大Equity DD 7.5%を警戒線とする。
- 全期間の結果と四半期結果を別々に保存する。

### 5. 比較集計

- Net Profit、PF、RF、Sharpe、Equity DD、Trades、実約定ロット、deal系列を原設定と比較する。
- 同一リスク化できなかった戦略を無理に順位付けしない。

## 実行負荷

- MT5は直列実行する。
- 実行プロセスは可能な限り`BelowNormal`かつ2論理CPU相当に制限する。
- 最初に短期パイロットを完了し、結果を確認してから約1年の7戦略へ進む。
- 中断・再開可能にし、完了済みケースを再計算しない。

## テスト

- deal volume抽出の単体テスト
- 原set不変、派生setの変更対象限定、ハッシュ保存のテスト
- 不正な入力名、重複、拡大率超過の拒否テスト
- manifestの完全性と中断再開のテスト
- 実データ実行前に全自動テストを`uv run`で完了する。
