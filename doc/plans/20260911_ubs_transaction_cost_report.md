# UBS取引コスト耐性 総合報告書の作成計画

## 目的・方針

利用者依頼により、完了済み112件を「目的・結果・詳細」の順で報告する。既存報告書・利用者編集・生データは上書きせず、MT5を再実行しない。

## 実装順序

1. 既存のS=0/生成物検証、HTML指標・deal・ロット解析、戦略/期間定義、SVGテーマを共有した報告書生成モジュールを追加する。uvで管理し、実行run・result・入力set・HTMLの整合性を再確認して112件の欠落/重複を拒否する。
2. 4WFのNP参考合計とS=0との差、四半期DD最大、WF別NP差、取引系列・取引数・会計内訳を集計する。合計NPを年間連続成績、DD最大を年間DDと呼ばない。PF/RF/Sharpeの合計・平均は行わない。
3. 新規doc/reports/ubs_transaction_cost_comparison.mdと専用assetsを生成。Sの定義を初出前に説明し、第1層の位置づけ、3層、カスタム銘柄の意味、4WF期間、固定lot、基準更新理由、品質制限と未知期間でない点を明記する。全112件の指標表と出典を残す。
4. 4水準の比較図とS=10のWF別差を作り、数値・単位・差の式・凡例を明示する。既存SVGテーマを共有し、プレビューで文字・重なりを確認する。
5. 集計・欠落/重複・ハッシュ・上書き防止・図の構造の単体テスト、全体テストをuvで実行し、生成物を検査する。新しい閾値や運用合否は後付けしない。
