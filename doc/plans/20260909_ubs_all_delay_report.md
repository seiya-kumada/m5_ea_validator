# UBS 7戦略の約定遅延耐性報告書

## 作成方針

利用者の指示により、先行2戦略40件と追加5戦略100件を統合し、目的・結果・詳細の順で新しい総合報告書を作成する。既存2戦略報告書と利用者編集済み報告書は保持する。

1. 既存の結果読込処理を対象戦略指定に対応させ、ハッシュ・ケース構成の検証を共用する。
2. 2runの条件・EAハッシュ・基準manifestを照合し、7戦略140件の重複や欠落を拒否する。No Delay再現、固定lot、入力・ティック監査を再確認する。
3. 4期参考合計NP、遅延によるNP差、期間別DD最大の3図と、戦略×WFのランダム平均NP差図をSVGで生成する。共通SVGスタイルを使用し、数値・単位・差の式を図内に明記する。
4. 7戦略概要表・28組の四半期比較表・約定系列比較表・140件の詳細表を掲載する。期間、ExecutionMode、3回反復、7.5%の根拠の限界、DD未整合の3戦略、4期合計と年間連続運用の違いを説明する。
5. 自動テストで統合監査・集計・SVG構造と出力保護を検証する。生成物を確認して完了報告する。
