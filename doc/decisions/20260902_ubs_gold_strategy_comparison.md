# UBS Gold 7戦略比較 決定履歴

## 2026-09-02: 比較開始時の方針

### 背景

`Sets_v6_faithful14/Sets_v6_faithful14/`にある14 setを確認した結果、実設定値`ForceSymbol=XAUUSD`のsetは7個だった。利用者は、この7戦略を実運用に近い条件で比較し、後から総合報告書へまとめることを希望している。

### 決定

- 最初に互換性、正しいTester時間足、資金管理設定を確定する。
- 原setは変更せず、SHA-256と主要入力値を基準情報として保存する。
- 原set忠実比較と同一リスク比較を分ける。
- 短期スモークテスト後に、既存WF1～WF4相当期間の28件へ進む。
- 生データと段階別集計を`data/ubs_strategy_comparison/`へ保存する。
- 最終報告書と画像は`doc/reports/`へ保存する。

### 理由

- フォルダ名はv6系だが、2026-09-02時点のUBSデモ版はv7.5であり、パラメータ互換性を先に確認する必要がある。
- 7 setの`LotPerBalance_step`、`HistoricalMaxDD`、`MaxTrades`などが同一ではなく、原設定の利益額だけでは戦略能力とリスク量を分離できない。
- 一部setはファイル名からTester時間足を特定できず、内部設定`ST1_Timeframe`をTester時間足と断定できない。
- 段階別の成果物を残すことで、最終報告書の数値と判断を再検証できる。

### 影響

- 正しいTester時間足または互換性を確定できないsetは、本試験を開始しない。
- 資金管理を変更する場合は原setを複製した派生setだけを使用する。
- 今後、期間、モデル、リスク正規化、ストレス値などを変更する場合は、この文書へ変更理由と影響を追記してから実装・実行する。

## 2026-09-02: Phase 0 初回目録

### 実施結果

- `ForceSymbol=XAUUSD`の7 setを目録化した。
- 全入力値、主要設定、ファイルサイズ、更新日時、SHA-256を保存した。
- UBSデモEAは401,828 bytes、SHA-256は`96c3af879d409bda7f57d7efa210b81555bcb2b2edcd2921ab584cbc1e6cc1a0`だった。
- 保存先は`data/ubs_strategy_comparison/inventory/20260902T005739271582_3662c8c7/`とした。
- Tester時間足は証拠未確定のため、7件とも`unresolved`として保存した。

### 判断

目録生成は原setとEAを読み取るだけとし、原本を変更しない。時間足を内部設定から推測して確定することはせず、互換性確認と明示的な根拠の調査をPhase 0の次工程とする。
